# Anleitungen für den Verein

Diese Anleitungen sind für alle gedacht, die die Webseite pflegen oder nutzen – ohne Technik-Vorkenntnisse.

| Anleitung | Für wen |
|---|---|
| [Die Verwaltung bedienen](verwaltung.md) | Redakteure und Administratoren: Seiten, Beiträge, Termine, Anfragen, Bilder, Himmelsobjekte, Menüs, Benutzer, E-Mail, Updates |
| [Himmel heute und Himmelsobjekte](himmel.md) | alle: was heute Nacht zu sehen ist, Darkmode, Objekte und Doppelsterne suchen |
| [Der Mitgliederbereich](mitglieder.md) | alle Mitglieder: Termine, Helfer, Beobachtungsplan, Dokumente, Vereins-E-Mail, Konto |
| [Server einrichten, aktualisieren, Fehler beheben](server.md) | wer sich um den Server kümmert – Schritt für Schritt zum Abtippen |

## Wer darf was?

| Rolle | darf |
|---|---|
| **Administrator** | alles – auch Benutzer, Einstellungen, E-Mail, Sicherungen, Wartungsmodus |
| **Redakteur** | Inhalte pflegen (Seiten, Beiträge, Termine, Galerie, Medien) und Links prüfen |
| **Mitglied** | Mitgliederbereich: interne Termine, als Helfer eintragen, Dokumente, Vereins-E-Mail |

Konten gibt es nur per **Einladung** durch einen Administrator (Verwaltung → Benutzer).

## Hilfe holen

Wenn etwas nicht klappt: einen **Screenshot** machen (Windows: `Windows-Taste + Umschalt + S`, Mac:
`Cmd + Umschalt + 4`) und ihn mit einer kurzen Beschreibung („Was wollte ich tun? Was ist passiert?“) an die
Person schicken, die sich um die Webseite kümmert.
